# C Cloud

Simple Cloud CLI application.

Cloud storage runs on a server and offers simple features:
1. ```Upload ```files.
2. ```Download``` files from the server.
3. ```View```and browse uploaded files.
4. ```Exit```the program
## Build


```bash
make all 
```
Run:
```bash
./server
```

Then:

```bash
./client
```

Default port: TCP `6543`.
`The port is left on default for simplicity and ease of testing without extra configuration.`
